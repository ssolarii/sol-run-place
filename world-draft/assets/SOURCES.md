# Asset sources

- `botanical-kit.json`: four fern clumps from [Fern 02](https://polyhaven.com/a/fern_02), modeled by Rico Cilliers and scanned by Rob Tuytel. [CC0](https://polyhaven.com/license). Prepared in Blender 5.2.3 using the official Blender MCP server: shared vertices, Y-up coordinates, preserved UVs and normals. Includes original shaped stones and a beveled timber mesh authored for this scene.
- `fern-rgba.webp`: the asset's 1K diffuse and alpha maps combined in Blender, then compressed for the web. Source files checked against the published Poly Haven manifest checksums. No runtime requests to Poly Haven.
- `shifty-schedule.jpg`: existing project screenshot, as documented in the route README.

Blender source is retained in the local project work folder as `archive-assets.blend`; portable Blender and MCP source remain local development tools and are not deployed.
